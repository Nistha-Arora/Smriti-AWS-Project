🌿 Smriti – AWS Cloud Project

📌 Project Overview

Smriti is a cloud-based memory assistance website designed with a simple and user-friendly interface. This project demonstrates the implementation of cloud computing concepts using Amazon Web Services (AWS) and the deployment of a website using AWS cloud infrastructure.

The project was developed to explore cloud services, website hosting, virtual servers, storage management and access control.

🎯 Project Objectives

- To understand and implement cloud computing concepts.
- To deploy a website using Amazon S3 Static Website Hosting.
- To explore virtual server infrastructure using Amazon EC2.
- To implement cloud storage using Amazon EBS.
- To understand network configuration using Amazon VPC.
- To explore identity and access management using IAM.

☁️ AWS Services Used

1. Amazon VPC (Virtual Private Cloud)

Used to create and manage the networking environment for AWS resources, including network configuration and connectivity.

2. Amazon EC2 (Elastic Compute Cloud)

Used to create and manage a virtual server in the AWS cloud environment.

3. Amazon S3 (Simple Storage Service)

Used to store frontend files and host the website using S3 Static Website Hosting.

4. Amazon IAM (Identity and Access Management)

Used to manage identities, permissions and access to AWS resources.

5. Amazon EBS (Elastic Block Store)

Used as block storage attached to the EC2 instance for persistent storage.
